# Currency Converter

A modern and visually appealing currency converter website that provides quick currency conversion through a clean and interactive interface. The project combines functionality with design, featuring a smooth infinite background video that creates an immersive user experience.

Built using HTML, CSS, and JavaScript, the website focuses on responsive design, user interaction, and a visually engaging layout.

## Features
- Real-time currency conversion interface
- Clean and responsive design
- Interactive and user-friendly layout
- Smooth infinite background video
- Lightweight and fast performance

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Purpose
This project was created to improve frontend development skills by combining JavaScript functionality with modern UI design and creative visual elements.
